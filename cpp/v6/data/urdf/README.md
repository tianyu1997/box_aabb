# Exp.5 Drake URDFs

Exp.5 now uses the upstream mesh-based robot description packages stored under
`cpp/v6/data/urdf/upstream/`.

- Panda: `moveit_resources_panda_description/urdf/panda.urdf`
- UR5: `ur_description/urdf/ur5.urdf`

These are the authoritative URDF inputs for the current Exp.5 visualization
pipeline.
