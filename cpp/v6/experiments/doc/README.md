# experiments/doc

这里保留的是历史实验计划和分项说明，主要用于回看早期设计、实验拆解和问题排查。

## 当前状态

- 本目录不是当前 v6 论文实验的执行入口。
- 其中部分文档仍包含旧环境、旧路径或旧平台命令；应视为历史记录，而不是当前运行手册。
- 当前论文口径请优先看上一级的 `../README.md` 与 `../paper/README.md`。
- 当前论文实验编号以 `../paper/` 下脚本前缀为准：Exp.2 是 `02_link_envelope_pipeline.py`，Exp.3 是 `03_marcucci_envelope_build.py`，Exp.4 是 `04_e2e_baselines_combined.py`。

## 如何使用

- 需要理解某个实验块最初是如何拆分时，可以查看对应的 `EXP*.md`。
- 例如 `EXP3_E2E_PLANNING.md` 记录的是历史 E2E planning 拆分，不再定义当前论文的 Exp.3 编号。
- 需要实际 rerun 当前论文实验时，不要直接照搬这里的命令，先核对当前 v6 的脚本入口与结果目录。
- 若后续继续清理本目录，原则是“保留背景、去掉误导”，而不是把历史分项文档当作活跃说明层继续扩写。

## 边界说明

- 这里的历史文档可以提到 v5、Windows、`build_x64` 等旧上下文；这不代表当前 v6 的推荐用法。
- 当前目录之所以保留，是为了给实验结果和论文口径演化提供背景，而不是作为新的结构中心。
