# experiments/scripts

这里保留的是较早期的 phase/stage 风格实验驱动层，主要用于分阶段复现、基线补跑和诊断，不是当前论文的主入口。

## 目录角色

- `phase*.py`: 按实验阶段拆分的批处理脚本。
- `run_all.py`: 旧式整批运行入口。
- `run_s1.py`, `run_s3s4_fast.py`, `run_s3s4_isolated.py`: 面向局部实验块的旧式启动器。
- `regression_test.py`: 回归检查脚本。
- `old/`: 更早期的保留脚本。

## 当前建议

- 论文 rerun 优先使用 `../paper/` 下的包装层。
- 只有在需要补跑阶段性基线、做历史对照或追查旧实验行为时，再回到这里。
- 如果一个逻辑同时存在于这里和 `../paper/`，通常以后者作为论文输出口径，以这里作为历史执行层。
