# experiments/scripts/old

这里是 `cpp/v6/experiments/scripts` 下的归档层，保存更早期的实验驱动脚本。

## 目录角色

- 保留旧版总入口、旧版论文生成脚本和针对单一工作负载的临时包装层。
- 这些文件可用于历史对照，但不再代表当前 v6 的论文实验入口。

## 当前约定

- 当前论文实验优先看上一级的 [cpp/v6/experiments/scripts/README.md](cpp/v6/experiments/scripts/README.md) 以及 `../../paper/`。
- 若这里的脚本仍提到旧结果目录、旧论文路径或旧命名，只按历史记录理解。
- 只有在需要复查旧实验行为时，才从这里进入。
