# scripts/old

这里是 `cpp/v6/scripts` 下的归档层，存放已经退出默认工作流的旧脚本。

## 使用边界

- 默认不要从这里启动当前论文实验、表格生成或基线复现。
- 仅在需要追查历史行为、比对旧输出格式或借用旧实现片段时，再回看这些文件。
- 如果旧脚本里的路径、环境变量或结果口径与当前 v6 不一致，以外层的 [cpp/v6/scripts/README.md](cpp/v6/scripts/README.md) 和当前活跃脚本为准。

## 维护原则

- 这里优先保留，不主动扩写成功能入口。
- 若某个旧脚本重新变得活跃，应迁回上层目录并补充文档，而不是继续留在 `old/` 内。
